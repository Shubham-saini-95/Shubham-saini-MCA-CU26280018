# Lab Sheet 04 — Python Programming Lab
## List and Dictionary Operations

This folder contains separate Python files for all 30 questions in Lab Sheet 04.

## How to run
1. Open this folder in VS Code.
2. Open a question file, for example `Q01_sum_average.py`.
3. Run it using the **Run Python File** button or terminal:
   ```bash
   python Q01_sum_average.py
   ```
4. Enter input when prompted.

## Notes
- Some questions use sample dictionaries/lists where the question does not require dynamic input.
- Q2 rotates the list to the right.
- Q6 places the extra item in the first half when the list length is odd.
- Q9 demonstrates flattening a one-level nested list.
- Q24 assumes dictionary values are unique for a lossless inversion.
